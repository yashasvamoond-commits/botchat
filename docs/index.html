Add a paper

Paste the text of a rent agreement, notice, order, affidavit — English, हिंदी or اردو. It is read on this phone; nothing is uploaded.

eCourts memory

Paste or choose the eCourts Case Status text once. Every CNR, court, stage and next hearing date is kept on this phone for good.

Backup

Everything on this phone, in one file you can keep or move to another device.

What this can do

  • Read English, Hindi and Urdu papers: type, date, parties with roles, amounts, court, case numbers and sections.
  • Search in any of the three languages — by party, type, month or year.
  • Keep eCourts case status text forever: ecourts, next hearing, or a CNR number.
  • No server, no account, no upload. PDF and Word files need the hosted version — here paste the text or send a .txt.

Tip: in Safari tap Share → Add to Home Screen to keep it as an app.

Runs entirely on this device.
